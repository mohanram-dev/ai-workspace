# Instructions for AI coding assistants

Read **[`CLAUDE.md`](CLAUDE.md)** in full before making any change in this repository. It is the development contract: architecture, conventions, the things that must not be changed casually (§21), the workflow for a change (§29) and the rules for assistants (§30).

Then read [`CONTRIBUTING.md`](CONTRIBUTING.md), in particular "Contributing with an AI coding assistant".

The one rule above all others: **no fake functionality**. Never simulate browser results, MCP responses, terminal output, agent execution or test results. If something is not built or not verified, say so.

`apps/web/AGENTS.md` holds Next.js 16 breaking-change notes generated by Next itself; read it before writing Next-specific code.
